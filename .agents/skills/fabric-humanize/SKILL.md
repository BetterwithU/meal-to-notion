# Fabric Humanize & Plain Language Skill

Derived from [danielmiessler/fabric](https://github.com/danielmiessler/fabric) (`patterns/humanize`, `patterns/improve_writing`, `patterns/clean_text`).

## Core Principles

1. **Eliminate Jargon & Developer-Speak in End-User UI**
   - Replace technical implementation details (e.g. "DB 렌더링", "API 파서", "도메인 모드", "런처") with the real-world domain terms used by people in that environment (e.g. teachers, students).
2. **Cut Significance Inflation & Forced Excitement**
   - No "혁신적인", "완벽한", "통합 솔루션", "차세대 AI 파서". State what it is plainly and factually.
3. **Clarity & Brevity Over Bloat**
   - Use short, active, plain sentences. If a label or badge doesn't change what the user does next, eliminate it.
4. **Natural Rhythm & Professional Warmth**
   - Sound like a helpful, respectful colleague, not a marketing bot or a database terminal.
